# Retail Sales Data — Exploratory Data Analysis (EDA)
## Internship
Oasis Infobyte Data Analytics Internship — Level 1, Task 1
## Objective
To explore retail sales data and identify patterns in sales, product categories, customer gender, and customer age.
## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
## Dataset
The dataset contains retail transaction details, including customer age, gender, product category, quantity, price, and total amount.
## Analysis Performed
- Inspected the first rows and dataset structure.
- Checked data types and missing values.
- Checked duplicate records.
- Generated descriptive statistics.
- Compared total sales by product category.
- Compared total sales by gender.
- Examined the customer age distribution.
- Compared quantities sold across product categories.
## Visualizations
Charts are saved in the `results` folder:
1. Sales by product category
2. Sales by gender
3. Customer age distribution
4. Quantity sold by product category
## How to Run
Install the required libraries:
```bash
python -m pip install pandas matplotlib seaborn
``
Run the analysis:
```bash
python retail_sales_eda.py
```
